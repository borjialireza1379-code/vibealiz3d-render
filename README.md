# vibealiz3d-render
Cloud renders for the Vibealiz3D YouTube channel: 3D "guess the song" videos made with Remotion + three.js.
Pushing a changed `render.json` renders the video on GitHub Actions in parallel parts (`chunks`) and uploads `final.mp4` as an artifact.
Melodies are short instrumental re-creations synthesised in code for a music quiz; all rights to the original compositions belong to their owners. Fonts: Anton and Chakra Petch (SIL Open Font License).
